# Maintainers

This document lists the maintainers of the `nvidia-oci-samples` repository and the escalation path for issues that need attention beyond a normal pull request review.

## Maintainers

| Name | GitHub | Role |
| --- | --- | --- |
| Anurag Kuppala | [@akuppala21](https://github.com/akuppala21) | Maintainer |
| Felipe Garcia | [@rhossi](https://github.com/rhossi) | Maintainer |

Maintainers are responsible for:

- Reviewing and merging pull requests
- Triaging and responding to issues
- Cutting releases and updating the [CHANGELOG](./CHANGELOG.md) if/when one is added
- Keeping the repository's documentation and samples accurate and up to date

## Escalation Path

1. Open a [GitHub issue](https://github.com/NVIDIA/nvidia-oci-samples/issues) and `@`-mention the maintainers listed above.
2. If an issue is not acknowledged within a reasonable timeframe, escalate by tagging additional maintainers on the issue or pull request.
3. For security-related concerns, **do not** open a public issue — follow the disclosure process in [SECURITY.md](./SECURITY.md).
